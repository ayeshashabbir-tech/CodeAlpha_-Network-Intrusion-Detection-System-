# Task 4: Network Intrusion Detection System

Tools: Python + Snort rules simulation
Features:
1. NIDS engine monitoring traffic.log
2. Custom Snort rules in local.rules (SQLi, XSS, Brute Force, Port Scan, ICMP Flood)
3. Alert logging in alerts.log
4. Response: block IP (simulated) + log
5. Visualization: attack_graph.png via dashboard.py

How to run:
python nids.py
python dashboard.py
